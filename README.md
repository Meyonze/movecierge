# 転シェルジュ

> 引っ越し時の手続きを、旧住所・新住所と家族の状況に合わせて整理できるチェックリスト

**公開URL：<https://meyonze.github.io/movecierge/>**

転シェルジュは、引っ越しで必要になる転出・転入の手続き、ライフラインや住所変更などを、迷わず進めるための無料のWebツールです。旧住所と新住所の市区町村名、あてはまる条件を選ぶと、必要な項目だけを一覧にします。

## できること

- 全国1,740市区町村から旧住所・新住所を検索
- 転出届・転入届の窓口情報と公式案内へのリンクを表示
- 国民健康保険、介護、子ども、車、犬など、状況に応じた手続きを追加
- 引っ越し予定日から、転出・転入の目安を日付つきで表示
- 年末年始、年度末・年度初め、大型連休に重なる場合は窓口の閉庁・混雑を注記
- 完了した項目をこの端末のブラウザに保存
- チェックリストの共有リンク、コピー、印刷に対応

## データについて

- 全国1,740市区町村を検索できます。
- このうち1,569自治体の窓口情報・公式案内を収録しています。
- 個別情報が未収録の自治体では、全国共通の手続き案内と公式サイト検索へのリンクを表示します。
- 必要書類、期限、開庁日、手続き方法は変更されることがあります。最終確認は必ず各自治体・事業者の公式案内で行ってください。

## プライバシー

入力した市区町村、引っ越し予定日、選択条件を、運営者のサーバーへ送信・保存することはありません。チェックの完了状態のみ、この端末のブラウザ内に保存されます。アクセス数・閲覧ページのパス・表示速度などは、Cloudflare Web Analyticsで匿名の集計データとして計測します。

詳しい利用規約・プライバシーは、公開ページ最下部の折りたたみから確認できます。

## リポジトリ構成

```text
index.html                     # 画面・動作本体
data/cities.json               # 全国の自治体一覧
data/city_data.json            # 窓口情報・公式案内URL
data/city_data_review.json     # 公開前の確認対象
scripts/validate-data.mjs      # データの検証
scripts/validate-ui.mjs        # 画面の構文・主要操作の検証
docs/DATA_QUALITY.md           # データ品質の基準
```

## 開発・確認

このリポジトリは静的なWebサイトです。ローカルで確認する場合は、簡易HTTPサーバーを起動して `http://localhost:8000/` を開きます。

```bash
python3 -m http.server 8000
```

データや画面を変更した場合は、公開前に次の検証を実行します。

```bash
node scripts/validate-data.mjs
node scripts/validate-ui.mjs
```
