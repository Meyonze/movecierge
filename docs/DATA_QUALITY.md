# 自治体データの品質管理

`data/city_data.json` は利用者に表示するデータ、`data/city_data_review.json` は公開前に人が確認する候補データです。自治体IDは `data/cities.json` を正とします。公開データの `confidence: low` は窓口情報のみを先行掲載した暫定データで、画面上でも要確認と明示します。

## 現在の監査結果

`node scripts/validate-data.mjs` の確認対象は、全国1,740自治体、本データ1,569件、レビュー用データ0件です。

- 本データには `confidence: high` が1,541件、`low` が19件、信頼度未設定が9件あります。
- 本データのうち20件は、転出・転入の公式案内URLのどちらかが未収録です。`low` の19件は、公式検索への導線と要確認表示を出します。
- レビュー用データは0件です。新規候補は、公式URLと窓口情報がそろうまでレビュー用データに置きます。

この数値はデータ更新時に変わるため、実際の作業では検証スクリプトの出力を正とします。

自治体ごとの確認リストが必要な場合は、`node scripts/validate-data.mjs --json` を実行します。標準出力のJSONには、警告の種類ごとに自治体ID・自治体名・都道府県・公開データとレビュー用データの信頼度が含まれます。

## 更新手順

1. `zenkoku_hikkoshi_research.py` の結果は、まずレビュー用データとして扱う。
2. 転出・転入の公式URL、窓口説明、対象自治体IDを確認する。
3. 公式URLと窓口情報を確認できたものは `confidence: high` で `data/city_data.json` に反映する。窓口情報のみ確認できたものは `confidence: low` とし、画面で要確認を明示したうえで公式検索へ案内する。
4. `node scripts/validate-data.mjs` を実行し、構造エラーがないことを確認する。
5. URL不足・信頼度未設定・競合の警告を確認してからPRを作る。

## 優先順位

1. 本データでURLが不足している1件
2. 本データの信頼度未設定497件
3. レビュー用データの未完成候補

URLの存在だけで内容の正しさは保証されません。自治体の公式サイト上で、転出・転入の対象手続きと窓口が一致することを確認します。
